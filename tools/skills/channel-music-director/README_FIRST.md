# History + Football + Explainer Music Director

This is a custom **Claude Skill** designed for direct ZIP upload to claude.ai. It contains 25 music research leads, repeatable editing/selection instructions, practical commands, and an A/B testing template. **It does NOT contain audio recordings.**

## Install on Claude web
1. Open https://claude.ai/customize/skills/yours (or Customize > Skills).
2. Click + > Create skill > Upload a skill.
3. Select the entire `channel-music-director.zip`; do NOT unzip to upload individual files.
4. Turn the skill on.
5. Open a chat with Claude and paste the MASTER COMMAND from `COMMANDS.md` (or from the ChatGPT response).

The app may require Skills and code execution/file creation to be enabled. Mobile interfaces vary; using the browser is the most reliable upload path.

## Suggested routine
For every new video, paste your script and ask Claude to run the skill. For ongoing channel management, keep the catalog and test log updated rather than assuming trends last forever.

## No automatic downloads
Claude can give audio search terms and edit instructions. It should not pretend songs are licensed for re-upload or download copyrighted material into your folders without permission.

## Mandatory audio balance
Background music is subordinate to narration. During speaking, start with music about 15–20 dB quieter than narration and automatically duck it; confirm by listening to the final rendered video. Claude should select the track for every video **when this skill is used**, but actual embedding/mixing requires access to an editing workflow or video tools.
