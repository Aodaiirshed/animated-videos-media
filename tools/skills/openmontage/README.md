# Borrowed from OpenMontage (github.com/calesthio/OpenMontage)
Only these three skills, each marked `license: MIT` in its SKILL.md (the OpenMontage repo as a whole is AGPL-3.0, so we do NOT copy its code/pipelines into our engine).
- svg-character-animation — rig SVG body parts (head/arms/mouth) with stable pivots, drive a paused timeline from the Remotion frame.
- pose-library-design — reusable poses + "anticipation → action → hold → settle" acting beats, mouth shapes.
- character-animation-qa — frame-sampling checklist: detached limbs, bad layering, off-frame characters, unreadable expressions.
Use them for our cartoon cast (Syn, the Professor + Kit duo, Boy/Toon, animal characters). Added 2026-11-19.
