# Visual Storyboard Director

## Input
An approved short-form script, preferred creative style, tools available, duration, and channel. If style/tool not provided, use cinematic high-contrast 3D for science, stylized graphic silhouettes for football, and mobile phone editing via CapCut or Instagram Edits.

## Deliverables
1. Production brief: main viewer emotion, audience, format, runtime, portrait 9:16 resolution 1080 x 1920 and export as clean original file.
2. Shot table for 4–8 shots: start/end time, narration, on-screen text, subject, setting, camera framing and motion, SFX, asset source, and transition.
3. Individual copy-ready AI image/video prompt for EVERY shot, with consistent central character/model/style and a separate negative-constraints clause. Prompts must be specific enough to be reproducible, not generic words like 'amazing cinematic viral scene'.
4. Caption file content in SRT text if given finalized voiceover timing; otherwise time-stamped text lines to align after recording. Keep captions in a mobile-safe zone away from bottom/right UI.
5. Simplest editing route in CapCut or Instagram Edits: import assets, place voiceover, trim, animate, add captions, adjust music under dialogue, export without visible platform watermark, upload natively.
6. Originality/compliance pass: disclose AI where applicable; no recycled watermarked TikTok versions; use licensed music and rights-cleared images/footage; don't promise algorithm favor for use of a particular editor.
7. End with a scene-level risk check on facts, sudden unsafe flashes, and confusing visual analogies.

## Production constraints
- Prioritize hook frame and legible captions; don't fill every second with particle effects.
- When the user requests actual generated video, be transparent: a skill provides plans/prompts, not video rendering on its own without supported video tools.
- Brand signatures: football = mystery/reveal; science = compelling physiological mechanism and cinematic explanation.

## Example
'Use visual-storyboard-director for this 24-second science script. Make five coherent 3D visual prompts and a CapCut assembly list.'
