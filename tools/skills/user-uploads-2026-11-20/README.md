# Claude Shorts Growth Pack — 5 Custom Skills (November 2026)

Tailored to two English Shorts channels: Football Guess the Player / footballer stories, and Science animated explainers / What If.

## Installation (Claude web)
- Depending on rollout, open **Plugins** in sidebar (the former **Customize**) and filter for Skills; or visit **Customize > Skills**.
- For a custom upload, choose Add/+ > Create skill > Upload a skill, if shown.
- Upload the **individual ZIP** for each skill (one ZIP per skill), not this outer bundle.
- Toggle the skill on if necessary. Ensure Code execution/file creation is enabled in Claude settings if skill controls are unavailable.
- Test: "Use Shorts Performance Auditor. Here is my YouTube Studio data; diagnose the 1,000-view plateau without guessing."

### Install order
1. shorts-performance-auditor.zip
2. viral-hook-and-pacing-lab.zip
3. football-shorts-story-director.zip
4. science-shorts-explainer-director.zip
5. shorts-experiment-operator.zip

## What each does
- **Performance Auditor**: diagnose using engaged views, Stayed to watch, retention, and 24h/72h/7d comparisons.
- **Hook & Pacing Lab**: generate distinct 0-2s opens, first frames, pacing, payoff and tests.
- **Football Director**: verifiable football mystery writing and original visual storyboards.
- **Science Director**: evidence-aware animated science scripting, including What If assumptions.
- **Experiment Operator**: test plan, editorial calendar, and data feedback loop.

## Analytics template
Use `shorts_analytics_template.csv` if not uploading screenshots directly. Empty fields mean not available; do not invent numbers.

## How to prompt Claude
"Use my Shorts Performance Auditor and Shorts Experiment Operator on the attached Studio export. Compare same-age videos separately for Football and Science. Find the 3 highest-leverage changes and build a 14-day controlled test. Then use Hook and Pacing Lab and the relevant channel director to make production-ready briefs. Do not invent analytics, factual claims, or algorithm thresholds."

Important: Custom skills are instructions and procedures, not a new model or an automatic live YouTube connection. You must provide YouTube Studio analytics/export or separately set up authorized access. Human review of factual claims, copyright, and quality is required.
